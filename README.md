# Neon Jump 霓虹跳跃

一个单文件 HTML 小游戏。Doodle Jump 风格 + 赛博朋克霓虹视觉 + WebAudio 合成音效。**默认 Hardcore 难度**:平台稀疏、一次性平台高频、移动平台快、弹簧极少。

## 玩法

- **← →** 或 **A / D** 移动 · 屏幕左右边缘可穿越
- **空格** 暂停 · **R** 重开 · **M** 静音
- 移动端按住屏幕左/右半边

## 平台

| 颜色 | 类型 | 行为 |
| --- | --- | --- |
| 🟦 青 | 普通 | 标准跳板 |
| 🟪 粉 | 弹簧 | 弹得超高 |
| 🟨 黄 | 一次性 | 踩一下就碎 |
| 🟣 紫 | 移动 | 自己左右滑 |

## 运行

直接双击 `neon-jump.html` 用浏览器打开即可。无依赖、无后端、无外部资源。最高分存在 `localStorage`。

## 技术

- 纯 Canvas 2D + `requestAnimationFrame`
- WebAudio 纯代码合成跳跃 / 弹簧 / 破碎 / 死亡音效
- Swept AABB 碰撞检测,杜绝高速穿透
- 视差星空 + 粒子爆破 + `shadowBlur` 发光
